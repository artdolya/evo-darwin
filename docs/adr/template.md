# NNNN. Title of the decision

Copy this file to `docs/adr/NNNN-short-title.md`, where `NNNN` is the next free number. Replace the text under each heading, delete this paragraph, and add the new file to the index in `docs/README.md`. An accepted ADR is not rewritten. To change a decision, write a new ADR and set the status of the old one to "Superseded".

## Status

One of: Proposed, Accepted, Superseded by NNNN (with a link to the new ADR). Add the date of the last status change as YYYY-MM-DD.

## Context

The situation that requires a decision: the problem, the constraints, and the options that were considered. State facts. A reader who was not there must be able to understand why a decision was needed.

## Decision

What was decided, in full sentences: "We will ...". Give the reason for choosing this option over the others.

## Consequences

What follows from the decision: what becomes easier, what becomes harder, what the team now has to do or must not do, and what has to be revisited later.
